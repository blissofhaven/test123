# Ввод исходных данных оборудования

Выберите аппарат или КЛ/ВЛ на схеме. Основные параметры доступны справа;
двойной щелчок открывает полную карточку. На обозначении перехода между
листами двойной щелчок по-прежнему открывает связанный лист.

## Карточка

1. Введите известные значения. Рядом с числом указана единица; длину можно
   вводить в метрах или километрах, мощность в кВА/МВА, ток в А/кА.
   Запятая и точка принимаются одинаково. Смена единицы не меняет значение.
2. Для параметра укажите источник: паспорт, протокол, расчёт или обоснованное
   допущение. Отметку «Проверено» ставьте после проверки этого значения.
   Изменение числа снимает прежнее подтверждение.
3. Нажмите «Проверить изменения»: появятся различия и перечень данных,
   необходимых для КЗ(3), КЗ(2), КЗ(1) и КЗ(2,1).
4. «Применить» сохраняет правки одной операцией; «Отмена» закрывает
   неприменённый черновик. Уже применённые правки отменяются общей командой
   «Отменить» в редакторе. Файл на диске обновляется кнопкой «Сохранить».

Неизвестное значение можно оставить пустым. Пусто, численный ноль и
«Путь отсутствует» — разные исходные данные. Допущение Z2 = Z1 выбирается
явно; его нельзя одновременно использовать с заданным Z2.

Для источников и генераторов доступны общие Z2/Z0 и отдельные значения
max/min. Пустое поле конкретного режима использует общее значение;
если отсутствуют оба, соответствующий расчёт недоступен. Указывается
ступень напряжения, к которой приведены сопротивления.

У составной линии каждый конструктивный участок имеет отдельную карточку
в переключателе сверху. Изменение одного участка не заполняет остальные.
ТТ вводится в карточке присоединения: первичный и вторичный ток, класс
точности, физическая сторона установки. Сторона не зависит от стрелки линии.

## Таблица и Excel

Откройте «Таблица параметров…». По умолчанию показан текущий лист;
можно выбрать весь проект, тип оборудования и строки с пропусками.
Фильтр типа открывает его собственные столбцы.

Выберите начальную ячейку и вставьте прямоугольный блок из Excel. Значения
попадут в показанные строки в их текущем порядке, в том числе после
сортировки. Пустые ячейки ничего не стирают. Для удаления значений есть
отдельная кнопка «Очистить явно».

Сначала нажмите «Проверить все изменения». Ошибки показаны по ячейкам;
пакет с ошибками не применяется частично. После исправлений нажмите
«Применить проверенные изменения». Источник и подтверждение выбранной
ячейки редактируются отдельной кнопкой. Закрытие таблицы отбрасывает
неприменённые правки.

## Справочник проекта

В меню «Исходные данные» откройте «Справочник проекта…», выберите тип и создайте марку.
Справочник хранится в том же файле проекта и заполняется вашими данными.
Для КЛ и ВЛ используются соответствующие типы марок.

Сохранение марки само по себе не изменяет установленное оборудование.
Выберите нужные аппараты, получите сравнение и отметьте поля для обновления.
Ручные значения сохраняются по умолчанию; их замена требует отдельного
выбора. Источник и подтверждение паспортных данных могут переноситься
вместе с маркой. Длина линии и место установки ТТ относятся к экземпляру
и из марки не переносятся.

## Расчёт после правок

После применения исходных данных прежние результаты помечаются устаревшими.
Запускайте новый расчёт отдельной кнопкой после ввода нужных аппаратов.
Неподтверждённое Z0 не блокирует КЗ(3) и КЗ(2); оно проверяется при
запросе повреждения на землю. Подтверждения чисел не заменяют проверку
физической модели и достаточности исходных данных.

Температура проводника, описание нейтрали и ответвлений трансформатора
пока сохраняются как дополнительные исходные данные. Они не создают
автоматически новую схему замещения. Заданный Z0 уже должен включать
применимое 3Zn; программа не добавляет его повторно. Минимальный режим
по-прежнему использует температурный коэффициент методики.

Класс точности ТТ, тип терминала, полное время отключения и другие поля,
пока не используемые формулами, отмечены в подсказках карточки.
Отдельные изображения ТТ, вторичные цепи, насыщение и новые настройки
защит относятся к следующим этапам.
