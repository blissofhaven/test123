# Размещение оборудования на холсте

## Область документа

Этот документ описывает UX выбора, предварительного просмотра и
фиксации оборудования. Электрический выбор операции
`INLINE_SERIES`/`BRANCH_ATTACHMENT`/`NODE_REPRESENTATION`/`MANUAL_SELECTION`
описан в [поведении размещения](equipment-placement-behavior.md).

## Активация из библиотеки

Позиция `EquipmentLibraryTree` содержит только payload будущей вставки.
Текущий контракт:

- один щелчок — одноразовая вставка;
- `Shift` + щелчок — многократная вставка;
- включённое действие «Многократная вставка» на командной панели —
  многократная вставка для последующих выборов из библиотеки;
- drag-and-drop из библиотеки — один явный drop, он не закрепляет
  многократный инструмент.

Поле `placement_repeat` извлекается до сохранения payload. Оно описывает
способ работы GUI, а не параметр оборудования.

## Предварительный объект

До подтверждения `DiagramGraphicsView.drawForeground()` рисует только
ghost-preview. Он показывает:

- габарит и угол будущего объекта;
- две базовые портовые точки;
- безопасный зазор;
- проекцию на физическую трассу;
- намерение последовательной вставки или отпайки;
- синий цвет для допустимого места и красный для коллизии.

Для трансформатора, реклоузера, выключателя и разъединителя есть
упрощённые предварительные символы. Остальные типы показываются общим
прямоугольником. Это не полный рендер конечного SVG-символа.

Ghost-preview не добавляет `EquipmentInstance`, `Port`, `ElectricalNode`,
`Connection`, `GraphicalRepresentation` или запись undo. Поворот клавишами
`R`/`Shift+R` также меняет только предварительный угол. Угол
нормализуется к одному из `0/90/180/270` без накопления ошибки.

## Коллизии до фиксации

Для оборудования `geometry_for_equipment_preview()` строит временную геометрию,
а `DiagramCollisionService.check_placement()` сравнивает её с телами объектов
той же страницы. Подписи, рамки выбора и чисто графические точки
соединения не становятся твёрдыми телами.

Отклонённое место не создаёт объект и не добавляет undo-шаг.
Одноразовый инструмент при этом остаётся активным, чтобы пользователь
мог выбрать другое место.

## Фиксация

1. Вид посылает `addEquipmentRequested` только после проверки места.
2. `EditorCanvas` разрешает capability типа через `EquipmentPlacementRegistry`.
3. Контроллер выполняет одну проектную команду. Она может быть простым
   добавлением, последовательной вставкой, отпайкой или представлением узла.
4. После успеха холст обновляется и выбирает представления, возвращённые
   результатом команды.
5. Одноразовая вставка переходит в `SELECT`; многократная сохраняет
   инструмент.

Проектная команда, а не предварительный жест, определяет границу одного
undo-шага.

## Ориентация на линии

Если `orientation_mode` не равен `manual`, ghost-preview на физической
трассе автоматически выбирает 0° для горизонтального сегмента и 90° для
вертикального. Нажатие `R` или `Shift+R` переводит предварительный объект
в ручную ориентацию.

Физическое место разбиения линии всегда вводится отдельно. Проекция курсора
на трассу не становится расчётной длиной.

## Отмена и запреты

- `Esc` отменяет активную вставку без изменения выбора.
- ПКМ при активном preview отменяет вставку, очищает payload и возвращает
  `SELECT`, не открывая контекстное меню.
- Пробел или средняя кнопка мыши отменяют активную вставку перед временным
  панорамированием; автоматического возврата к ней нет.
- В режиме «Анализ» вставка отклоняется до создания объекта.
- Отмена диалога ручного выбора, терминала или физического расстояния
  не создаёт модель и отменяет только эту попытку фиксации. Активный one-shot
  и preview остаются для повтора; завершить их можно `Esc` или ПКМ.
