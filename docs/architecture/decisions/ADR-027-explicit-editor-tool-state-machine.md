# ADR-027: явная машина состояний инструментов

- Статус: принято в UI-UX-1
- Дата: 2026-08-28

## Контекст

Вставка, провод, перемещение, рамка, панорамирование и поворот preview —
взаимоисключающие намерения. Набор независимых GUI-флагов допускает
невозможные сочетания, неоднозначный `Esc` и расхождение между командной
панелью и холстом.

## Решение

Ввести Qt-независимую `EditorToolStateMachine`. Она хранит ровно один
`EditorTool`, payload, имя, угол preview, режим `EDIT`/`ANALYSIS` и, если нужно,
состояние возврата из поворота.

Каждый вход в инструмент и выход из него выполняются явным переходом.
`EditorToolTransition` содержит предыдущий и текущий снимки, признак принятия,
русское сообщение и явные эффекты вроде `clear_selection`.

Машина проверяет:

- взаимоисключение инструментов;
- наличие payload для вставки;
- дискретность угла 90°;
- запрет edit-only инструментов в режиме «Анализ»;
- двухступенчатую семантику `Esc`;
- разное завершение успешной одноразовой, успешной многократной и
  отклонённой вставки.

`DiagramGraphicsView` владеет машиной. `DiagramGraphicsScene` и командная панель
получают её снимки, но не владеют второй копией активного инструмента.

Специализированные `ConnectionToolState` и `PhysicalLineToolState` пока остаются
владельцами геометрии своего черновика. При старте и завершении они
зеркалируют общее намерение как `DRAW_CONNECTION`/`SELECT`.

## Отклонённые варианты

- независимые флаги `is_placing`, `is_drawing`, `is_panning` в разных виджетах;
- определение инструмента по форме курсора;
- хранение активного GUI-инструмента в модели проекта;
- создание undo-шага на каждый переход GUI;
- блокировка выбора и панорамирования в режиме «Анализ».

## Последствия

- переходы можно проверять без Qt;
- командная панель показывает то же состояние, которое обрабатывает холст;
- первый `Esc` отменяет операцию, второй снимает выбор;
- вход в «Анализ» детерминированно отменяет edit-only операцию;
- фактическое перемещение объекта, перемещение точки/сегмента трассы и
  рамка по свободному полю явно переводят машину в `DRAG_OBJECT`,
  `DRAG_ROUTE_SEGMENT` и `MARQUEE_SELECT`, а завершение жеста возвращает
  `SELECT`;
- перемещение подписи и один шаг стрелками клавиатуры не используют
  промежуточное `DRAG_OBJECT`.
