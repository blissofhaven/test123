# ADR-022: дискретное вращение оборудования на 0/90/180/270 градусов

- Статус: принято в Этапе UI-UX-1
- Дата: 2026-08-28

## Контекст

Редактор должен позволять ориентировать выключатели, реклоузеры,
трансформаторы и другие символы по направлению схемы. Произвольный вещественный
угол усложнил бы ортогональные трассы, накопил бы погрешность после повторных
поворотов и сделал бы положение портов неоднозначным. В то же время хранить
поворот только внутри `QGraphicsItem` нельзя: после сохранения, загрузки и
undo/redo графический документ должен воспроизводиться без состояния Qt.

## Решение

Новые редакторские команды ориентации принимают только четыре канонических
угла: `0°`, `90°`, `180°` и `270°`. Кратные `90°` нормализуются по модулю
`360°`, остальные значения отклоняются. Существующее поле
`GraphicalRepresentation.rotation_deg` остаётся `float` для совместимости
формата, но команды UI-UX-1 не записывают в него произвольные углы.

Загрузчик сохраняет совместимый входной конверт: конечный угол старого проекта,
например `45°`, не приводит к отказу загрузки и не округляется скрыто при
повторном сохранении. Неразрушающая проверка проекта выдаёт предупреждение
`diagram.legacy_non_quarter_rotation` и предлагает пользователю явно выбрать
одно из четырёх положений. Это не миграция формата и не команда undo/redo.

Qt-независимый модуль `rza_calc.editor.orientation` содержит:

- `QuarterTurn`;
- нормализацию угла;
- поворот экранной точки и направления;
- вычисление портовых якорей;
- поиск ближайшего направленного ортогонального сегмента.

Угол сохраняется в `GraphicalRepresentation.rotation_deg`. Режим выбора угла
сохраняется отдельно как `AUTO` или `MANUAL` в `stage3_graphics`.

Ручной поворот всегда переводит представление в `MANUAL`. Явная команда
автоориентации переводит его в `AUTO` и выбирает угол по подключённым трассам
либо по переданной подсказке. Старое представление без режима читается как
`MANUAL`.

Изменение угла и локальная перестройка всех инцидентных портовых трасс являются
одной командой `ProjectCommandHistory`. Если маршрутизация или проверка
целостности завершается ошибкой, проект не получает частичного изменения.

## Отклонённые варианты

- произвольный угол с плавающей точкой;
- хранение угла только в Qt-объекте сцены;
- изменение угла без перемещения графических окончаний трасс;
- полная перестройка всех маршрутов проекта при повороте одного символа;
- изменение электрических соединений вслед за экранной стороной порта;
- автоматический поворот legacy-проектов без сохранённого режима.
- автоматическое округление произвольного legacy-угла при загрузке: для `45°`
  выбор между соседними четвертями неоднозначен и может изменить геометрию
  портов без согласия пользователя.

## Последствия

- четыре последовательных поворота на `90°` точно возвращают исходный угол;
- горизонтальная и вертикальная последовательная вставка имеют однозначную
  ориентацию, включая обратное направление `180°/270°`;
- undo/redo восстанавливает угол и зависимые трассы одним шагом;
- электрический fingerprint при чистом повороте не изменяется;
- свободное вращение и групповой поворот не входят в текущий контракт;
- `AUTO` не является фоновым наблюдателем всей топологии: повторный подбор угла
  выполняется явной командой или в сценарии вставки.
- старый произвольный конечный угол остаётся доступным для просмотра и
  lossless roundtrip, но виден в общей диагностике до явного исправления.
