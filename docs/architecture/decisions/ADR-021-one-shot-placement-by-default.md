# ADR-021: одноразовая вставка по умолчанию

- Статус: принято в UI-UX-1
- Дата: 2026-08-28

## Контекст

После выбора элемента из библиотеки неявно закреплённый инструмент легко
создаёт лишние копии при следующем щелчке по холсту. При этом для массовой
расстановки нужен явный повторяющийся режим.

## Решение

Обычный одиночный щелчок по позиции библиотеки активирует
`PLACE_EQUIPMENT_ONCE`. После одной успешной проектной команды редактор
возвращается к `SELECT`.

Многократная вставка активируется только явно:

- `Shift` + щелчок по библиотеке;
- включение действия «Многократная вставка».

После успеха `PLACE_EQUIPMENT_REPEAT` сохраняет payload и угол до `Esc`, ПКМ
или явного перехода к другому инструменту. Отклонённая из-за коллизии фиксация
не считается успехом и оставляет оба режима активными. Отмена промежуточного
диалога также оставляет preview для повторной попытки.

Drag-and-drop остаётся одним явным drop и не закрепляет инструмент.

## Отклонённые варианты

- всегда оставлять вставку закреплённой;
- полагаться только на двойной щелчок для активации;
- после ошибки молча выключать одноразовый инструмент;
- сохранять `placement_repeat` как свойство доменного объекта.

## Последствия

- случайный следующий щелчок не создаёт копию;
- массовая расстановка остаётся быстрой, но явной;
- недопустимое место можно исправить без повторного выбора типа;
- контракт не меняет электрическое поведение capability-реестра;
- режим вставки остаётся GUI-состоянием и не загрязняет проект.
