# ADR-001: разделение Domain Model и Diagram Model

- Статус: принято на Этапе 1
- Дата: 2026-08-25

## Контекст

Исторический SVG-viewer выводит представление из `core.Network`, имён и шаблонов ID. Это смешивает электрическую семантику с раскладкой и не позволяет безопасно иметь несколько страниц, ручную маршрутизацию и стабильное редактирование.

## Решение

`ElectricalModel` является единственным каноническим источником оборудования, портов, электрических узлов, подключений и режимов. Она не хранит координаты, SVG и viewport.

Diagram Model будет отдельным слоем. Её элементы обязаны ссылаться на стабильные domain ID. Несколько diagram elements могут отображать один domain-объект, а изменение их геометрии не меняет электрическую связность и не требует пересчёта topology.

`ProjectStructure` остаётся переходной физико-навигационной структурой, но не заменяет ни электрическую, ни будущую графическую модель.

## Последствия

- Имена и координаты нельзя использовать для определения connectivity.
- Domain-команды и diagram-команды имеют разные инварианты и revisions.
- Удаление визуального элемента по умолчанию не удаляет оборудование.
- Будущая версия project format получит отдельную diagram-секцию.
- Существующий SVG-viewer остаётся legacy-представлением до отдельного этапа миграции.

## Текущее ограничение

На Этапе 1 Diagram Model и интерактивный редактор не реализованы; ADR фиксирует границу, а не готовую функцию.
