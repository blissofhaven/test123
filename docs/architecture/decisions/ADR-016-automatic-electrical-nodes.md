# ADR-016: автоматические электрические узлы только по явной команде

- Статус: принято перед Этапом 4.6.1
- Дата: 2026-08-28

## Контекст

При присоединении к середине ВЛ/КЛ пользователь ожидает получить настоящий
электрический узел без ручного создания служебных объектов. Одновременно
графическое попадание курсора в линию, пересечение трасс или предварительный
просмотр не должны
самопроизвольно менять топологию.

Для отпайки нужен один общий узел. Для последовательного аппарата нужны два
разных узла по его сторонам; один общий узел создал бы электрический обход.

## Решение

Служебные `ElectricalNode` создаются только внутри атомарной доменной или
проектной команды после явного электрического жеста пользователя.

- разбиение и отпайка создают один узел;
- последовательная вставка создаёт два разных терминальных узла;
- узел имеет постоянный ID, но не является `EquipmentInstance` и не получает
  каталожную запись;
- `junction_kind` и `creation_origin` являются диагностическими метаданными,
  а не отдельным законом топологии;
- маркер предварительного просмотра существует только в состоянии GUI и не
  сериализуется;
- физическое положение передаётся как `offset_mm`, отдельно от координат.

Если длина неизвестна, допускается `offset_mm=None`. Получившиеся части
остаются неподтверждёнными и блокируют расчёт; геометрия не используется как
замена длине.

`ProjectCommandHistory` фиксирует электрическую модель, диаграмму и
каталожные снимки одним шагом после общей проверки целостности.

## Отклонённые варианты

- создавать соединение при любом визуальном пересечении;
- сохранять предварительный просмотр как полусозданный объект проекта;
- определять число узлов по SVG-символу;
- использовать один узел по обе стороны последовательного аппарата;
- вычислять физическое положение по доле пиксельной трассы.

## Последствия

- пользователь получает автоматизацию без скрытой электрической эвристики;
- отменённый жест не требует undo;
- одна ошибка не оставляет осиротевший узел или половину разбиения;
- один узел поддерживает любое число ветвей;
- коммутационный аппарат действительно способен разорвать активный путь.
