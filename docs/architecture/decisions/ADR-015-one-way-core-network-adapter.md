# ADR-015: односторонний адаптер к `core.Network`

- Статус: принято на Этапе 4
- Дата: 2026-08-26

## Контекст

Старое расчётное ядро принимает `core.Network`, тогда как редактор Этапа 4
работает с типизированными объектами, портами, узлами, линиями и режимами в
`ElectricalModel`. Двусторонняя синхронизация создала бы второй источник истины:
изменение старого DTO могло бы разойтись с канонической схемой, а
неподтверждённая линия — исчезнуть из одной модели и остаться в другой.

## Решение

Поток данных только односторонний:

```text
ElectricalModel
    -> проверка целостности и готовности данных
    -> активная топология выбранного режима
    -> односторонний адаптер
    -> новый совместимый core.Network
```

Редактор и команды никогда не изменяют `core.Network`. После успешной доменной
транзакции совместимое представление строится заново. Обратной синхронизации из
`core.Network` нет.

Целостный проект с неизвестной длиной или неподтверждённым сопротивлением можно
сохранить и продолжить редактировать. Адаптер выдаёт типизированную блокирующую
диагностику, а `ProjectData.require_calculation_ready()` запрещает запуск
расчёта. Совместимый placeholder для старой навигации не является расчётной
сетью и не может использоваться в обход этой проверки.

Редактор получает эти диагностики только для чтения. Он сопоставляет их с
объектами и трассами по постоянным ID, показывает встроенные значки проблем,
фактическое число ошибок в нижней панели и итоговый статус выбранной трассы в
режиме разработчика. Отсутствие переданных данных обозначается явно и не
подменяется нулём ошибок.

## Последствия

- объектная электрическая модель остаётся единственным источником истины;
- сохранение никогда не читает изменения обратно из `core.Network`;
- каждый расчёт получает представление, соответствующее одной проверенной
  revision модели и выбранному режиму;
- неподтверждённая физическая линия не объявляется достоверной и не участвует
  в расчёте с нулевыми либо угаданными параметрами;
- старое ядро обновляется только после успешной атомарной электрической
  операции;
- несовместимое или неполное состояние блокирует расчёт целиком, а не создаёт
  отличающийся «тихий» граф.
