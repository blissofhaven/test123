# ADR-006: отпайка как обычный многосвязный узел

- Статус: принято на Этапе 2.5
- Дата: 2026-08-25

## Контекст

Специальная структура «parent/child» для отпайки запрещает кольца, несколько
ветвей из одной точки и продолжение основной линии. Графическая точка также не
может сама определять электрическое соединение.

## Решение

Отпайка — обычный `ElectricalNode` произвольной степени. Создание отпайки одной
транзакцией:

1. разделяет выбранную электрическую ветвь по физическому расстоянию;
2. создаёт узел между двумя новыми ветвями основной линии;
3. сохраняет их принадлежность исходной `LogicalLine`;
4. переносит `LineConstructionSegment` без потери порядка и длины;
5. подключает одну или несколько отходящих ветвей;
6. проверяет целостность и перестраивает производные представления.

Удаление отпайки является отдельной командой. Если остаются две однозначные
ветви одной логической линии, они могут быть объединены с конкатенацией
конструктивных участков. Неоднозначное объединение не выполняется автоматически.

## Последствия

- Основная линия всегда продолжается после узла.
- Количество и вложенность отпаек не ограничиваются.
- Один undo восстанавливает исходную линию целиком.
- Простое пересечение графических маршрутов не создаёт Connection.
- Положение будущего клика преобразуется в физическое расстояние до доменной
  команды; экранная координата не является длиной.
- Питание после отпайки определяется общим графом, а не направлением рисования.
