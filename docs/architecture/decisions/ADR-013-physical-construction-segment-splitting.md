# ADR-013: разделение физических конструктивных участков

- Статус: принято на Этапе 4
- Дата: 2026-08-26

## Контекст

Одна электрическая ветвь может последовательно содержать несколько марок
провода, кабеля или шинопровода без промежуточного электрического узла. При
создании отпайки либо установке аппарата нужно разделить ветвь в физическом
месте и не потерять порядок, длины и удельные параметры. Разделение по
координате холста или пропорциональное распределение неизвестного общего
сопротивления дало бы недостоверный расчёт.

## Решение

Место разделения задаётся `offset_mm` от начала `LineSection`. Алгоритм
проходит упорядоченные `LineConstructionSegment` и:

- переносит целые записи слева или справа без изменения ID;
- при попадании внутрь одной записи создаёт две записи с новыми ID;
- сохраняет вид линии, свойства, расширения и признаки подтверждённости;
- меняет только длины двух частей;
- запрещает точку вне открытого интервала длины ветви.

Если длина неизвестна, разрешён только явный неподтверждённый split одной ещё
не распределённой записи. Обе части остаются с `length_mm=None` и
`length_confirmation=UNCONFIRMED`.

Подтверждённость сопротивления является типизированным полем данных. Она не
повышается автоматически после разделения. Доказуемое сохранение импеданса
основано только на подтверждённых удельных параметрах и физических длинах.

## Отклонённые варианты

- делить длину по пиксельной доле маршрута;
- создавать электрический узел при каждой смене марки;
- усреднять смешанные ВЛ/КЛ в один тип;
- пропорционально делить неизвестное общее сопротивление;
- сохранять один ID конструктивного участка у двух независимых новых записей.

## Последствия

- сумма подтверждённых длин двух ветвей равна исходной длине;
- для удельных r1/x1 сохраняется последовательный электрический эквивалент;
- граница марок без электрического действия не создаёт узел;
- порядок конструктивных данных восстанавливается при обратном объединении;
- неизвестные данные остаются видимыми и блокируют адаптер, а не получают
  вымышленные значения;
- сложную неизвестную смешанную ветвь необходимо сначала физически уточнить.
