# Контрольные примеры этапа 4.4

Дата проверки: **27.08.2026**. Допуск для прямых операций double precision:
`rel=1·10⁻⁹`, `abs=1·10⁻¹²`.

Автоматизация находится в
`tests/calculation_audit/test_benchmark_cases.py`. Независимый Ybus — в
`tests/calculation_audit/reference_solver.py`.

Идеальный источник в production-тестах выражен конечной мощностью
`Sкз=1·10¹⁸ МВА`. Получаемое `|Zс|≈1,1·10⁻¹⁶ Ом` ниже существующего порога
объединения `1·10⁻¹² Ом`; NaN и Infinity не используются.

## Пример 1 — один импеданс

- `Uл=10,5 кВ`, `Z=0,1+j0,4 Ом`.
- `|Z|=0,4123105626 Ом`.
- Эталон: `Iк3=14,7029408823 кА`.

Независимый и production-расчёты проходят.

## Пример 2 — две параллельные ветви

- Каждая ветвь `0,2+j0,8 Ом`.
- Эквивалент `0,1+j0,4 Ом`.
- Общий ток `14,7029408823 кА`.
- Ток каждой ветви `7,3514704412 кА`.

Независимый и production-расчёты проходят. Production возвращает только модуль
коэффициента токораспределения.

## Пример 3 — трансформатор 1 МВА

- `10/0,4 кВ`, `Uk=6 %`, `R=0`.
- Эталон `Iк3=24,0562612162 кА`.

Независимый расчёт на стороне 0,4 кВ и production проходят.

## Пример 4 — три последовательных участка

Каждый участок `0,05+j0,2 Ом`, `U=10,5 кВ`.

| Точка КЗ | Эталон, кА |
|---|---:|
| После первого участка | 29,4058817646 |
| После второго участка | 14,7029408823 |
| После третьего участка | 9,8019605882 |

Независимый и production-расчёты проходят. Топологические операции создания и
удаления отпайки проверяются отдельной группой тестов редактора/Domain Model.

## Пример 5 — два источника и реклоузеры

- Два идеальных синфазных источника, каждый через `0,1+j0,4 Ом`.
- Оба пути: `29,4058817646 кА`, по `14,7029408823 кА` от каждого.
- Один путь отключён: `14,7029408823 кА`, питание сохраняется.
- Оба пути отключены: `KeyError` со статусом «узел не запитан», не `0 кА`.

Production проходит числовую и топологическую часть примера.

## Пример 6 — ГТЭС → КТП 0,4 кВ

Выполнены два независимых представления одной цепочки:

1. расчёт в о.е. с `Sб=100 МВА` и базисами 10,5/110/10/0,4 кВ;
2. расчёт каждого элемента в омах его паспортной ступени с последующим
   приведением к 0,4 кВ по согласованным отношениям 10,5/110/10/0,4.

Оба способа дали один ток с допуском `rel=1·10⁻⁹`, `abs=1·10⁻¹²`.

| Величина | Эталон |
|---|---:|
| `RΣ*` | 1,4121551911 |
| `XΣ*` | 8,0361436299 |
| `|ZΣ*|` | 8,1592761152 |
| `Iк3` 0,4 кВ | 17,6899966687 кА |
| `I` 10 кВ | 0,7075998667 кА |
| `I` 110 кВ | 0,0643272606 кА |
| `I` 10,5 кВ | 0,6739046350 кА |

Оба независимых эталона проходят. Четыре production-проверки отмечены строгим
`xfail` по дефекту `AUD-SC-001`; подгонка входов или ожидаемых чисел не
выполнялась.
