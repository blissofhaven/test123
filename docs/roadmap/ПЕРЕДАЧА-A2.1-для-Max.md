## Разрешённое расширение границы

Заказчик явно разрешил точечную правку `rza_calc/io/project.py` 31.08.2026,
после отдельного запроса Sol. Разрешение записано в ТЗ до реализации.

Новые сигнатуры:
`load_project(path, *, methodology_override=None)` и
`load(path, *, methodology_override=None)`.
Override должен быть валидным Methodology; копируется независимо и сохраняется
как inline-reference. Внешний профиль не читается. Все проверки сети/ID/портов
и блокировка недостроенного проекта остаются. Без override старый путь сохранён.

Корневое поле `file` в override явно запрещено, поскольку текущий формат
использует его как внешнюю ссылку. Ключ не удаляется молча. Сам паспорт
сохраняет полное содержимое; API `case.replay(net)` не имеет этого IO ограничения.
