## Важное незакрытое замечание

**Нельзя принять эту выдачу как доказанное устранение вылета.** Windows
подтверждает три аварии Qt6Gui.dll / 0xc00000fd, но конкретный вызывающий путь
не найден. UI-CRASH-001 остаётся открытым. 160 последовательных обновлений
объясняют задержку, но не доказывают причину переполнения стека.

В полном MainWindow Windows/PySide6 проведены 384 перемещения и 16 показов
подсказок — авария не повторилась. Физической мышью заказчик результат ещё
не принимал. Для продолжения нужен повторяемый жест/объект или вывод окна
запуска после следующей аварии. Отдельную серую маску поверх подписи на самой
схеме также не воспроизвели; исправленный контраст относится к полям ввода.
