# Этап A4 — Справочники оборудования

**Трек:** A · **Исполнитель:** Max · **Зависит от:** A3 · **Оценка:** 5–7 дней

## Цель

Пользователь выбирает марку кабеля — параметры подставляются. Сейчас есть
только встроенная таблица `cables.json` и пользовательский каталог на уровне
Domain без интерфейса.

## Входной контроль

- A3 закрыт, модель параметров описывает обязательные, необязательные и
  пользовательские поля с единицами;
- `domain/catalog.py` и `domain/catalog_snapshot.py` существуют;
- `io/catalog.py` сохраняет пользовательский каталог в проект.

## Граница этапа

**Разрешено:** `rza_calc/domain/catalog*`, `rza_calc/io/catalog*`,
`rza_calc/data/**`, импорт таблиц, тесты, документация.

**Запрещено:** менять формулы; менять значения параметров существующих
демо-проектов.

**Числа:** не меняются.

## Состав работ

### 1. Встроенные каталоги (только чтение)

* силовые трансформаторы ТМ, ТМГ, ТДН, ТРДН: Sном, Uк, ΔPк, ΔPхх, Iхх, группа;
* кабели АПвП, ААБл, АПвПу: сечение, r0, x0, допустимый ток, удельный
  ёмкостный ток;
* провода АС: сечение, r0, x0, допустимый ток;
* выключатели и реклоузеры: Iном, ток отключения, время отключения, токи
  термической и динамической стойкости;
* ТТ и ТН: коэффициент, класс точности, номинальная нагрузка.

У каждой записи обязательно поле «источник данных». Значение без источника
в каталог не попадает.

### 2. Импорт из Excel/CSV

* сопоставление колонок с полями модели параметров;
* предпросмотр перед импортом;
* отчёт об отклонённых строках с причиной — **молча терять строки запрещено**;
* повторный импорт обновляет записи, а не создаёт дубликаты.

### 3. Пользовательский каталог проекта

Создание записи из экземпляра, изменение, удаление с проверкой ссылок.

### 4. Связь «экземпляр ↔ запись»

Экземпляр помнит, из какой записи взят и какие поля переопределены вручную.
При изменении записи — **явное предложение** обновить экземпляры, а не
автоматическая подмена.

### 5. Снимок каталога в проекте

Механизм `catalog_snapshot` уже есть: проект должен открываться и считаться
на машине без этих каталогов.

## Критерии готовности

* Выбор марки кабеля заполняет r0, x0, Ic и допустимый ток.
* Импорт таблицы не теряет строки молча.
* Проект, сохранённый с каталогом, открывается на машине без него.
* Видно, какие поля экземпляра переопределены относительно каталога.
* Тест-снимок расчётных чисел зелёный.
