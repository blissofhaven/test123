## Что работает и проверено

* **Ybus-решатель прямой последовательности.** Совпадение с независимым
  ручным расчётом до 1,1e-14 % на схеме «система → два трансформатора →
  включённый СВ»; коэффициент токораспределения 0,5000000000000001.
  Параллельная работа, кольца и несколько источников получаются из общей
  матрицы, без частных случаев в коде.
* **Объединение узлов ветвями нулевого сопротивления** вместо подстановки
  малого Z — матрица не теряет обусловленность.
* **Отказ вместо догадки**: в кольце ток через идеальную перемычку
  неоднозначен, `distribution_factor_complex()` бросает
  `CurrentDistributionError`, МТЗ становится «?».
* **Входная валидация.** Отклоняются: отрицательная Sкз, конфликт Sкз/Iкз,
  NaN и отрицательные R/X линии, отрицательное Uк обычного 2W.
* **Актуальность расчётного view.** `ProjectData` сверяет fingerprint модели,
  `ProjectViewModel.net` — свойство. Дефекты актуальности `AUD-TOP-002/003`
  закрыты.
* **Формулы элементов в омах** проверены размерно и численно:
  `Zт = 10·Uк·U²/Sном`, `X"d = 1000·x"d·U²/Sном`, `Rт = 1000·ΔPк·U²/Sном²`,
  `r0 = ρ/S`, `Zс = U²/Sкз`, `Zс = U/(√3·Iкз)`.
* **Рабочий ток** суммируется по полной мощности зоны и делится на напряжение
  стороны ТТ — корректно для любой ступени.
