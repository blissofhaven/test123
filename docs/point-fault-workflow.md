# Открытие проекта и расчёт КЗ в выбранной точке

Обычный запуск через `ЗАПУСК.bat` открывает светлое окно выбора. Можно открыть
недавний файл, выбрать другой, создать пустой проект или свою копию учебной схемы.
Автоматическое открытие последнего проекта включается отдельно; по умолчанию
оно выключено. Недоступный недавний файл не заменяется другой схемой незаметно.

Учебные варианты: большой нефтепромысел и [компактная сеть 110/35/10/0,4 кВ](compact-training.md).
При выборе учебного варианта создаётся новый файл: дальнейшее сохранение меняет
вашу копию. Существующий файл этим действием не перезаписывается.

## Открытие и переключения

При открытии загружаются данные и рисунок, полный расчёт не запускается.
Пока расчёта нет, численные результаты не показываются как готовые.
Подготовка большой сцены всё ещё занимает время; это изменение убирает из
открытия расчёт всех режимов, а не делает любую схему мгновенной.

Один щелчок выделяет аппарат. Двойной щелчок по выключателю меняет его положение
в черновике режима в редакторе и анализе. Если включено подтверждение переключений,
программа сначала спрашивает его. «Применить» фиксирует режим; «Сбросить» отменяет
черновик. Расчёт выполняется отдельно после применения. Карточка выключателя
доступна через «Свойства» и правую панель.

## Как посчитать выбранное КЗ

1. Выберите режим сети и примените незавершённые переключения.
2. Нажмите правой кнопкой на шину или подключённый вывод и выберите
   **«Рассчитать КЗ здесь…»**. Для выделенного аппарата доступна кнопка **«КЗ в точке…»**.
3. У аппарата с несколькими выводами выберите физическую сторону.
   У КЛ/ВЛ доступны начало и конец. Внутренняя точка линии по расстоянию пока
   не подключена к этому расчёту; координата мыши не заменяет электрическую длину.
4. Отметьте нужные виды КЗ и нажмите **«Рассчитать выбранные КЗ»**.

Доступны ABC, BC, AG и BCG: трёхфазное, двухфазное, однофазное на землю
и двухфазное на землю. В этом диалоге повреждение металлическое, **Z = 0 Ом**.
Работа идёт в фоне с отменой. Вычисляется выбранная точка в выбранном режиме,
автоматический расчёт всех защит и остальных точек не выполняется.

Рядом появляется один блок с цветными строками, обозначением вида КЗ и током
в **кА на ступени выбранной точки**. Цвет дополняет подпись. Для BCG краткий
итог — `max(|IB|, |IC|)`; оба тока отдельно доступны в подробностях по нажатию
на блок. Там же указаны фазные токи, углы, 3I0 и принятые допущения.

Если данных для одного вида КЗ недостаточно, соответствующая строка содержит
«нет результата» и объяснение в подробностях. Числа других доступных видов
сохраняются. Неизвестные Z0 и путь возврата через землю не подменяются нулём.

Изменение электрических исходных данных или режима скрывает прежние числа.
Перемещение рисунка само по себе не требует нового расчёта: блок следует за
точкой привязки. Повторный запрос с теми же исходными данными использует кэш;
для другой точки может повторно использоваться подготовленная топология режима.

**«Полный расчёт»** остаётся отдельным действием для всего проекта. Точечный
результат не выдаётся за полный расчёт защит и не означает проверку уставок.

Во вкладке **«КЗ → Ветви и ТТ»** источник результатов выбирается явно:
точечный запрос или полный расчёт. После успешного точечного запроса выбран
именно он; затем можно выбрать вид КЗ и измеряемую ветвь. Если точечный результат
устарел, программа объяснит причину и не заменит его числами полного расчёта.
Первичные величины здесь — составляющие тока от КЗ, вторичные — идеальное
масштабирование по указанным номиналам ТТ; подробнее в [описании измерений](fault-branch-currents.md).

## Достоверность и следующий шаг

Все четыре вида КЗ используют схемы симметричных составляющих с заданными
Z1/Z2/Z0. Описание чисел и границ — в [документе о расчёте](calculation-audit/four-faults-explained.md).
Программная сверка контрольного примера не означает совпадение с EnergyCS ТКЗ:
отчётов из этой программы для сопоставления пока нет.

Дальше — приёмка поддержанных моделей и токов в местах ТТ, затем ввод собственных
МТЗ/ТО без направления и проверка обязательных сценариев. Внутренние точки линий,
рабочий режим, ёмкостное ОЗЗ/ДГР и подтверждённые исполнения терминалов остаются
отдельными пунктами [дорожной карты](roadmap/ROADMAP.md).
