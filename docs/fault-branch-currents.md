# Токи ветвей и ТТ при коротком замыкании

Откройте «Анализ и расчёты», выберите узел повреждения и вид КЗ. Внизу,
в разделе «КЗ», откройте «Ветви и ТТ», затем выберите нужную ветвь.
Режим — тот, который выбран в верхней панели. Расчёт должен быть актуальным.

Для ветви показываются доступные физические концы и, если ТТ задан,
значения на его стороне. Внутренняя опорная точка источника и точка звезды
эквивалента трёхобмоточного трансформатора не являются местами установки ТТ:

- фазные токи A/B/C и остаточный ток 3I0;
- токи каждого конца в кА на его собственной ступени напряжения;
- вторичные токи ТТ в А по указанным первичному/вторичному номиналам;
- пояснение отсутствующих исходных данных или неоднозначного результата.

**Показывается составляющая от КЗ ΔI.** Доаварийный ток нагрузки и
уравнительные токи параллельных источников к ней не прибавлены. Если в
контрольной задаче доаварийными токами пренебрегают, это используемый в ней
ток КЗ. При существенной нагрузке для полного аварийного тока понадобится
согласованное комплексное решение рабочего режима.

Положительное направление каждого конца — **из узла внутрь оборудования**.
Поэтому у обычной линии комплексные токи концов противоположны, хотя их
модули одинаковы. У трансформатора учитываются разные ступени напряжения,
сдвиг прямой/обратной последовательности и схема передачи нулевого тока.
Ток на стороне треугольника не получается простым масштабированием всех
фазных токов заземлённой звезды.

ТТ выбирается по сохранённому физическому узлу установки, а не по направлению
питания данного режима. Используется идеальное отношение:

    Iвтор, А = 1000 · Iперв, кА · Iном.втор / Iном.перв

Полярность вторичной цепи, схема соединения ТТ, насыщение и погрешности
не включены в этот первый просмотр. Отсутствующие номиналы или сторона
не заменяются типовыми значениями. Явно неподтверждённые параметры ТТ
блокируют вторичные значения; первичные токи ветви остаются доступны.
Для старых параметров без сведений о подтверждении показана отдельная отметка.

Ток единственной идеальной перемычки определяется балансом узлов. Если
несколько идеальных ветвей образуют замкнутый контур, их отдельные токи
не определяются однозначно: выводится причина, без подставленных половин
или нулей. При этом результат точки КЗ и определимые токи остальных ветвей
остаются доступны.

Новый сетевой результат также содержит изменения фазных напряжений ΔU.
Абсолютные остаточные напряжения штатно известны в самой точке КЗ.
Абсолютные U остальных узлов без доаварийных фазоров не подставляются.

Новая функция не расширяет модели трёхобмоточных трансформаторов для
несимметричных КЗ. Предельный расчёт двухфазного КЗ на землю при известной
разомкнутой сети нулевой последовательности пока не поддерживается.

## Связь с уставками

Действующие расчёты МТЗ/ТО пока используют прежний расчётный путь, включая
оценку Iк(2)=√3/2·Iк(3). Новый просмотр не заменяет их исходные токи незаметно.
При независимом Z2 такое приближение может отличаться от нового расчёта:
в контрольном примере K1 MAX — 5,376698 против 4,888578 кА.

Следующая работа — [ввод собственных уставок и проверка](roadmap/protection-input-plan.md)
по токам конкретного места ТТ и полному набору обязательных повреждений.

## Воспроизведение

Исправленный [контрольный проект ТКЗ-01](../tests/fixtures/control_examples/tkz_reference_01/README.md)
содержит независимый фазный эталон и отдельный файл для приложения.
В нём нет графической раскладки. Двигательная подпитка, ДГР и реальное
ёмкостное ОЗЗ этим примером не проверяются.

Сравнение с доступной лицензированной EnergyCS ТКЗ ещё не выполнено.
Цель — проверенные одинаковые модели и допущения, а не совпадение чисел
при разных исходных данных. Распределение токов ветвей и узловые напряжения
входят в состав [EnergyCS ТКЗ](https://www.energycs.ru/support/articles/cm_36_energycs.html).

## Техническое приложение: реализованные формулы

API `ShortCircuitSolver.fault_network_at(node_id, spec)` возвращает
`FaultNetworkResult` версии `sequence-branch-contribution-v1`; см. [реализацию](../rza_calc/core/fault_network.py).
Скалярные фазоры — Python `complex`; матрицы NumPy имеют `dtype=complex`
(`complex128` в используемом окружении). Столбец `Zbus[:, k]` получают решением
`Ybus · z = e_k` через `numpy.linalg.solve`, где `e_k` — единичный вектор;
см. [сборку комплексных матриц последовательностей](../rza_calc/core/sequence_network.py).

Пусть $s\in\{0,1,2\}$, $k$ — узел КЗ, $U_b$ — общая расчётная ступень,
$U_n$ — ступень узла, обе в кВ. Верхний индекс $b$ означает приведение к $U_b$.
Ток $I_{s,k}$ из `FaultResult.i012_ka` направлен в повреждение и задан в кА:
$$I_{s,k}^{b}=I_{s,k}\frac{U_k}{U_b},\qquad
\Delta\mathbf U_s^{b}=-\mathbf Z_{\mathrm{bus},s}[:,k]\,I_{s,k}^{b}.$$
$Z$ измеряется в Ом, поэтому $\text{Ом}\cdot\text{кА}=\text{кВ}$.
Ступени берутся из [stage_voltage](../rza_calc/core/impedance.py);
это коэффициенты приведения, а не предположение о доаварийном напряжении каждого узла.

Для конечной ветви $p\to q$ используются $y_s=1/z_s^{b}$ и безразмерный `tap` $t_s$:
$$\Delta I_{p,s}^{b}=\frac{y_s}{|t_s|^2}\Delta U_{p,s}^{b}
-\frac{y_s}{t_s^*}\Delta U_{q,s}^{b},\qquad
\Delta I_{q,s}^{b}=y_s\Delta U_{q,s}^{b}-\frac{y_s}{t_s}\Delta U_{p,s}^{b}.$$
Здесь $*$ — комплексное сопряжение; оба тока направлены **из своего узла в ветвь**.
Для трансформатора $t_1=e^{-j\theta}$, $t_2=e^{+j\theta}$, $t_0=1$ ($\theta$ — заданный сдвиг, переведённый в радианы);
отношение ступеней уже учитывается приведением, повторно в $t_s$ не включается.
Выдаваемые значения на физическом узле $n$:
$$\Delta U_{n,s}=\Delta U_{n,s}^{b}\frac{U_n}{U_b},\qquad
\Delta I_{n,s}=\Delta I_{n,s}^{b}\frac{U_b}{U_n}.$$

Нулевые `from_ground`/`to_ground` — отдельный шунт выбранного конца на GRID:
для конечного $z_0^b$ приведённый ток $\Delta I_0^b$ этого конца равен $\Delta U_0^b/z_0^b$, противоположного — нулю.
При `blocked` оба внешних нулевых тока равны нулю; это не утверждение известного $U_0$.
Идеальные ветви объединяются в матрице; токи мостов восстанавливаются по KCL
($\sum\Delta I_{\text{из узла}}+I_{s,k}^{b}=0$ в точке КЗ, без второго слагаемого в остальных узлах).
Идеальные контуры дают `None` для неоднозначных токов, а не условное деление между ветвями.

[Преобразование последовательностей](../rza_calc/core/fault_types.py) одинаково для токов и напряжений:
$$a=-\frac12+j\frac{\sqrt3}{2},\qquad
\begin{bmatrix}X_A\\X_B\\X_C\end{bmatrix}=
\begin{bmatrix}1&1&1\\1&a^2&a\\1&a&a^2\end{bmatrix}
\begin{bmatrix}X_0\\X_1\\X_2\end{bmatrix},\qquad 3I_0=I_A+I_B+I_C.$$
При неизвестной компоненте полная фазная тройка не выдаётся.
В точке КЗ проверяется $\Delta\mathbf U_{012,k}=\mathbf U_{012,k}-(0,E_k,0)$, где $E_k=U_{\text{до КЗ},k}/\sqrt3$ — фазная ЭДС в кВ;
старый точечный путь 3ph без фазового сдвига сохраняет `positive.z_th` и его порог объединения.
Формулы описывают составляющую от КЗ; доаварийные токи, измерительная схема ТТ и новые модели защит здесь не добавлены.
