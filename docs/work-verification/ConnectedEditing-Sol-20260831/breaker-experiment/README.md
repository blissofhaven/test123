# Экспериментальные данные, НЕ действующий проект и НЕ эталон

Эти файлы доказывают AUD-PROT-011 на отдельной временной модели с 64 добавленными выключателями. Производственные `energoraion.json`, `core/context.py` и `tests/baseline/calculation_baseline.json` не заменялись.

- `summary.json`: размеры опыта и количества расхождений.
- `existing-results-diff.json`: 35 добавленных ложных проверок; прежние поля совпадают в штатном допуске.
- `full-results-diff.json`: дополнительно 384 результата новых узлов.
- `before-full-snapshot.json`, `after-full-snapshot.json`: снимки исходной и экспериментальной сетей; не копировать в baseline.
- `before-zone-examples.json`, `after-zone-examples.json`: ID основной/резервной точки и их одинаковый представитель решателя.
- Два `before-vs-...-diff.json`: пустые результаты сравнения при временном исключении эквивалентных точек только в памяти. Это не производственная правка и не её приёмка.
- `migration-plan.json`: экспериментальный список аппаратов, новых узлов и необходимых переносов CT-привязок; не готовая миграция проекта.
- `switching-examples.json`: четыре выборочных испытания отключения/возврата питания.
- `draft-layout-verification.json`: геометрические проверки последнего временного макета.

Детали и оставшиеся ворота — в `docs/work-verification/connected-breakers-audit.md`. Чертёж DRAFT не включён как второй проект. Для воспроизведения нужен отдельный эксперимент с неизменённым входным проектом; указанные здесь данные не должны загружаться приложением как рабочая схема.
