## 5. Паспорт: реализованный контракт и граница

`MethodologySnapshot.as_dict()/from_dict()` сохраняет полный канонический JSON
профиля, включая неизвестные поля, и проверяет согласованность с полями для
отчёта и SHA-256. `to_methodology()` создаёт независимый профиль без чтения
внешнего файла и без подстановки текущих значений по умолчанию.

`CalculationCase` предоставляет `as_dict`, `from_dict`, `save(path)`,
`load(path)`, `to_methodology()` и `replay(net)`; формат
`rza-calculation-case/1`. Сохраняются fingerprint модели/методики, порядок ID,
версии приложения/ядра/алгоритма, время UTC и полный снимок. `save` никогда
не затирает существующий файл. Повреждённый/неполный паспорт, иной алгоритм
или ядро, другая модель либо порядок ID отклоняются. Replay создаёт новый
результат с реальным временем повтора, а не подделывает дату старого расчёта.

CLI `save-case <новый-файл.json>` сохраняет паспорт, сохраняя расчётные коды
0/1/3; ошибка записи даёт 2. CLI `replay-case <паспорт.json>` загружает ту же
электрическую модель с профилем из паспорта и печатает полный протокол. Прежний
файл методики не читается. Ошибочный паспорт или несовпадение входа дают 2,
расчётные коды 0/1/3 сохраняют свой смысл. Паспорт не содержит саму электрическую
модель: для replay нужна та же сеть. Старые неполные снимки не дополняются
молча текущей методикой. SHA-256 — проверка согласованности, не электронная подпись.

IO-контракт: `load_project(path, *, methodology_override=None)` и
`load(path, *, methodology_override=None)`. Явный Methodology проверяется и
копируется независимо; возвращённый ProjectData содержит inline-reference.
Последующее явное `save_project` создаёт самодостаточный профиль, а не ссылку
на прежний внешний файл. Проверки модели, ID, портов и блокировки расчёта
черновика не обходятся. Без override загрузка полностью сохраняет прежний путь.
Корневое поле `file` в override отвергается явно: в существующем формате оно
зарезервировано для внешней ссылки, а удалять неизвестное поле было бы потерей
данных. Сам паспорт это поле сохраняет; программный `case.replay(net)` с уже
полученной сетью не имеет этого ограничения IO.

Пример команд из корня проекта (паспорт должен быть новым файлом):

```text
python -m rza_calc rza_calc/examples/ps_severnaya.json save-case severnaya.case.json
python -m rza_calc rza_calc/examples/ps_severnaya.json replay-case severnaya.case.json
```
