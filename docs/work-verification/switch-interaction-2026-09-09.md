# Управление выключателями в редакторе и анализе

09.09.2026. Дополнение к проверенному блоку ядра `1ce00d1f24ca38e665276e69587f783c59665375`.

По запросу заказчика двойной щелчок по символу коммутационного аппарата
меняет его положение в черновике режима в обоих разделах. Один щелчок
выделяет; карточка доступна через «Свойства» и кнопку инспектора.
У линий, трансформаторов и непереключаемых перемычек двойной щелчок
сохраняет открытие карточки. Применение режима и расчёт остаются отдельными.

Причины недоступности управления: старые реальные QF нефтепромысла имеют
тип `legacy.tie`, который прежнее меню не распознавало; аналитическое
представление не передавало действия контекстного меню общему обработчику.
Исправлены обе причины. Старый аппарат определяется по коммутационному
символу, типу и явному `switchable=True`. Capability сам по себе недостаточен:
он также есть у старых линий и трансформаторов с вложенными выключателями.

Переключение адресуется каноническому ModeTarget оборудования. Геометрия,
электрическая модель и история до «Применить режим» сохраняются. Подтверждение
переключений соблюдается; отмена не меняет состояние. Работающий расчёт,
запрет переключений, вывод аппарата из работы и неизвестное положение
блокируют действие. Устаревший черновик показывает причину отказа.
