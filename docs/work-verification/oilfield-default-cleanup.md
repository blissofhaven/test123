# Нефтепромысел как единственный встроенный проект · 07.09.2026

Поручение: при запуске убрать прежнюю схему и оставить новый нефтепромысел.
Этап 3 не начат. Исходный коммит: `928559a69c296657c6ce2c9a33346843d40aaef8`.

## Причина и исправление

В GUI оставалась ПС «Промышленная» как первый проект и резерв при ошибке
восстановления. CLI и консольные запускатели тоже ссылались на старые примеры.
Запись последнего проекта сама по себе не исправляла первый запуск без
настроек. Теперь GUI, CLI `example`/`пример` и запускатели используют
`rza_calc/examples/oilfield_gtes.json`.

Девять старых встроенных JSON удалены из `rza_calc/examples` и перенесены
без изменения байтов в `tests/fixtures/legacy_projects`. Там же работают
прежние генераторы. Для сохранения относительных ссылок на методику добавлена
точная копия профиля в `tests/fixtures/data`; отдельная проверка подтверждает
равенство исходному профилю. Числовой эталон и его журнал не менялись.
Служебная однослойная автораскладка теперь требует явного пути проекта.

При автоматическом восстановлении распознаются прежние девять имён под
`rza_calc/examples`, в том числе из предыдущего расположения программы.
Существование старого файла не требуется: сразу выбирается нефтепромысел.
Свой одноимённый проект в другой папке продолжает открываться; явно переданный
путь также сохраняет приоритет. Пользовательские проекты по-прежнему
запоминаются после успешного открытия или сохранения.

## Начальный вид

Сохранённый масштаб 40% скрывал подписи, а панель ошибочно показывала 100%.
Панель теперь отображает фактический масштаб, включая непредустановленные
значения после колеса мыши или команды показа всей схемы.

Нефтепромысел открывается на I секции ГТЭС при 75%, центр `(-660, -60)`.
Это читаемый фрагмент большого листа; остальные части доступны перемещением
и масштабированием, другие площадки — через дерево проекта. Порог видимости
подписей не менялся. В JSON изменены ровно три значения начального вида:
масштаб и две координаты центра. Оборудование, электрические связи,
параметры, постоянные ID, маршруты и 34 листа сохранены.
