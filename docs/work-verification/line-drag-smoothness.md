## Изменения

- Каждая подпись повторно использует только свой последний перенос текста.
  Изменение текста, полного значения QFont, шрифта приложения, DPI, ширины
  строки или базы шрифтов сбрасывает результат. Метрики Qt не сохраняются.
- Неизменный фон сетки использует штатный CacheBackground. Сглаживание задано
  явно: без этого Qt рисовал кешированный фон иначе. При смене сетки, масштаба,
  размера окна и обзоре проверено совпадение с прежним рисованием.
- Повтор одной позиции привязки не повторяет построение геометрии и подписей.
  Для каждого нового положения выполняется прежняя полная расстановка текста
  и построение мостиков по текущим препятствиям. Таймеров и отбрасывания новых
  координат нет; полная раскладка не заменяется сохранёнными позициями.
- Отпускание мыши учитывает его координату и Alt даже без промежуточного move.
  Неподвижный щелчок не притягивает прежнюю геометрию к сетке; возврат в начало
  восстанавливает исходную трассу. Отмена и обновление документа сбрасывают жест.
