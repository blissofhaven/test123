# Первая загрузка действующего проекта в GitHub

Дата: 31.08.2026. Задание: по подтверждению владельца подключить существующую
рабочую папку к приватному `blissofhaven/test123`, сохранив историю репозитория.

## Исходное состояние и границы

- В GitHub до переноса был только `README.md` с заголовком `test123`.
- Родитель первого импорта: `46331082e397520162d50bd8ba62c4dfee4b0de5`
  (`Initial commit`). История сохраняется, force-push не применяется.
- Действующая папка на ПК не переносится и не дублируется.
- Изменения приложения и схем, полученные от Claude, сохраняются. Расчётный
  код, эталон, журнал эталона и `status.json` в этой задаче не исправлялись.
- В задаче добавлены только правила Git/состава коммита и инструкция совместной
  работы. Локальные кэши и crash-log остаются на ПК, но не публикуются.
- BAT/CMD хранятся без преобразования строк, чтобы исходный ZIP не сломал уже
  исправленный GUI-запуск. Это не является приёмкой всех остальных BAT-файлов.
- Файлы текущего проекта и исторические доказательства сохраняются в Git
  побайтово: нормализация CRLF/LF не должна менять входные JSON или делать
  сохранённые контрольные суммы неприменимыми к опубликованным файлам.
