## Результат

- Пункт «Электрический узел» убран из палитры. В разделе «Шины» остались
  горизонтальная и вертикальная шины. Существующие узлы не удалены;
  автоматическое создание узла при соединении объектов сохранено.
- Для новых действий интерфейса доступны два положения: 90° и 180°.
  Они согласованы между вставкой, свойствами, панелью, контекстным меню,
  автоматической ориентацией и клавишами R/Shift+R.
- У одного выделенного аппарата или шины есть векторный маркер поворота
  у верхнего правого угла. Он подсвечивается при наведении, сохраняет
  экранный размер при масштабировании и перетаскивается левой кнопкой мыши.
- Во время жеста виден предварительный угол. Отпускание записывает одну
  отменяемую операцию. Esc, потеря фокуса/захвата, смена выбора, инструмента
  или режима отменяют незавершённый жест.
- Наложение на другое оборудование отклоняется без частичного изменения.
  В режиме анализа маркер скрыт, изменение геометрии запрещено.
- Провода сохраняют свои порты и обходят корпус после поворота. Присоединение
  к шине перемещается вместе с ней, включая старые привязки без сохранённой доли.

## Совместимость

При открытии старых файлов углы 0°/270° и прочие сохранённые значения не
переписываются. В свойствах они обозначаются как сохранённое положение, пока
пользователь явно не выберет 90° или 180°. Низкоуровневый четырёхугловой API
сохранён для совместимости с файлами и другими потребителями; ограничение
двумя положениями относится к новым действиям интерфейса.

Поворот не меняет электрическую модель, ID/роли портов ВН/СН/НН, положение
контактов, количество узлов или соединений. Сам маркер является временным
элементом редактора и не сохраняется в проекте или векторном экспорте.

## Проверки

Полный прогон: **1240 passed in 114.37 s**. Из них 140 проверок — в новых
наборах для двух положений, палитры, маркера и маршрутов.

Команда из корня рабочего проекта:

```text
python -B -m pytest -q --capture=sys -p no:cacheprovider --junitxml=docs/work-verification/two-position-rotation/pytest-results.xml
```

Окружение: Python 3.14, PySide6 6.11.2, `QT_QPA_PLATFORM=offscreen`, UTF-8.
В финальном прогоне использован `--capture=sys`: первоначальный запуск с
перехватом файловых дескрипторов дал Windows `WinError 6` при запуске CLI
подпроцессов. Отдельные CLI-проверки и окончательный полный прогон прошли;
изменений расчётного продукта ради обхода этой ошибки не делалось.

Новые проверки:

- `tests/test_two_position_policy.py` — два положения, переключение preview,
  безопасная обработка угла, геометрия присоединений к шине.
- `tests/test_two_position_palette.py` — состав палитры, две команды и
  выбор положения в свойствах, сохранение старых углов, режим анализа.
- `tests/test_rotation_handle.py` — 15 сценариев с настоящими Qt-событиями:
  перетаскивание, предпросмотр, фиксация, undo/redo, Esc, потеря захвата,
  коллизии, масштаб, выбор/инструменты, автоматические узлы, старые шины.
- `tests/test_rotation_route_safety.py` — все терминалы выключателя и
  двух-/трёхобмоточных трансформаторов после поворота; подход с правильной
  стороны без прохода сквозь корпус; переключение от фактического AUTO-угла.

Проверки подтверждают графическое поведение редактора, а не пригодность
расчёта для выбора реальных уставок РЗА. Проверка физической мышью пользователем
не проводилась. Уже открытые экземпляры приложения не закрывались и не
перезапускались; для загрузки нового кода требуется обычный перезапуск.
