По SHA-256 сверены 95 защищённых файлов: всё приложение `rza_calc/` без
кэшей (93 файла), сохранённый эталон и журнал baseline. Изменений нет.
Все девять перенесённых исторических файлов побайтово совпадают с исходными.
Топология, сохранённые ID, роли портов, геометрия пользовательских схем и
численные данные не изменены этим переносом.

Полный прогон собрал 1962 теста, но не завершился: после продвижения до
GUI-набора (последняя полная строка прогресса — 77 %) перестал выдавать
результаты, процесс перестал накапливать процессорное время. Остановлен
только этот проверенный по PID и времени запуска тестовый процесс. Окна
пользователя не закрывались. Итоговой сводки полного прогона нет; причина
остановки GUI-набора в рамках уборки не установлена.

Найденные до остановки 11 отказов независимо воспроизведены в неизменённой копии
исходного коммита, полученной через `git archive`. В ней запуск двух модулей:

```text
python -m pytest -q -p no:cacheprovider --tb=short --basetemp <новый временный каталог> tests/test_bus_connection_spacing.py tests/test_editor_voltage_guard.py
11 failed, 41 passed in 1.17s
```

Те же два модуля отдельно запущены в текущем проекте после переноса:
`11 failed, 41 passed in 0.96s`. Набор отказавших тестов совпал.

- Восемь вариантов
  `test_new_independent_taps_have_distinct_exact_bus_endpoints`:
  расстояние 10.0 при ожидаемом минимуме 20.0.
- Три варианта
  `test_explicit_connections_reject_mismatch_and_unknown_before_any_mutation`:
  ожидаемое исключение `EditorCommandError` не возникло.
  Параметры: `port-None-second_voltage1`, `port-first_voltage2-None`,
  `node-None-second_voltage1`.

Чтение исходного кода уточнило расхождение: предварительная проверка
соединения запрещает неопределённое напряжение, а команда с `adopt=True`
принимает известный класс соседа. Такое различие между предварительной
проверкой и выполнением уже было в исходном коммите. Проверки несовпадения
двух известных классов в данном запуске прошли; эти три отказа сами по себе
не доказывают разрешение соединять известные 10 кВ с известными 110 кВ.

Следовательно, эти отказы существовали до уборки. Их тесты и код приложения
не ослаблялись и не исправлялись в рамках переноса. Нужно отдельно сверить
текущее поведение с требованиями; этот отчёт не объявляет весь проект
прошедшим приёмку.
