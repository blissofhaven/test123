## Правила объединения до измерения

1. Цвет/контакт/обмотки/шины/мостики и маркер поворота берутся из донора.
   Палитра остаётся общей для Qt и SVG. Состояние контакта не заменяет питание.
2. Низкоуровневый API и старые файлы сохраняют 0/90/180/270°. Новые действия
   интерфейса используют донорские два положения 90°/180°; существующие
   углы без явной команды не переписываются.
3. Единственный владелец подписей — B3: имя + параметр, ручное закрепление,
   сохранение/отмена, фильтры и скрытие ниже 0,6. Старые явные координаты,
   включая (0,-32), не признаются автоматическими по догадке.
4. По умолчанию текст остаётся горизонтальным по B3, включая линии.
   Отличие от донорских вертикальных названий сообщено заказчику до переноса.
5. Зазор подписей **4 единицы** не снижается. Проверяются видимые мостики,
   увеличенная толщина шин и провода, а не только исходные прямые waypoints.
6. Preview поворота и отмена обновляют подписи и середину трассы, но не
   меняют документ. Commit — одна отменяемая графическая команда.
7. Постоянные ID, роли портов, электрическая топология/fingerprint, исходные
   параметры и численные результаты сохраняются. Эталон не обновляется.
8. Существующие проверки не удаляются; меняются только ожидания явно
   принятого оформления/двухпозиционного UI с сохранением проверяемых инвариантов.
