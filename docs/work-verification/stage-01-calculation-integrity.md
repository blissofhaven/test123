## 1А. Актуальность результатов

После изменения электрических данных старый расчёт становится историческим снимком. Таблица КЗ, фазная расшифровка, уставки, проверки, селективность, электрическая карта и сводка допускают числа через одну проверку актуальности. Устаревание обозначается явно; вместо действующих чисел показываются прочерки. Незавершённое подключение нового аппарата также блокирует результат, даже если этот черновик ещё не попал в расчётную проекцию.

Пересчёт получает отдельную копию сети. Публикация проверяет текущие исходные данные и номер попытки: поздний старый результат или поздняя ошибка не заменяют более новый ответ. Ошибка новой попытки не оставляет прежний OK действующим. Версия алгоритма включена в проверку актуальности.

Команды редактора, undo/redo и переход в анализ обновляют панели Qt. Изменение геометрии не меняет электрическую актуальность. Выбор уже рассчитанного режима или вида КЗ использует актуальный снимок без обязательного повторения всего расчёта. Возврат undo к точно тем же исходным данным позволяет снова использовать соответствующий исторический снимок.

Подробная расшифровка заново получает строки текущего выбранного узла и вида КЗ: ранее сохранённые строки не могут вернуть старые числа даже после нового успешного пересчёта.

Контроль: `four_fault_types.json`, FAULT, max, BC–земля. При изменении длины линии командой контроллера с 2 до 20 км ток IB меняется с 11,2882674 до 1,8287278 кА. Между правкой и пересчётом видны прочерки и сообщение об устаревании. Проверено настоящее окно Qt; снимки до/после пересчёта просмотрены.

Существующий GUI показывает сводку в диалоге и не имеет экспорта файла инженерного протокола. Для выдачи действующего результата добавлена общая проверка `require_current_result`; новое действие экспорта не вводилось. Обычное сохранение проекта остаётся доступным.

## 1Б. Полнота МТЗ и итоговых результатов

Обязательные режимы определяются по физическому состоянию сети независимо от наличия успешного решателя. Пропущенные режимы, ошибки рабочих токов, неопределимые токи в точках и пустая обязательная основная зона больше не исчезают из проверки.

Для каждого условия записывается число проверенных и обязательных случаев, а также причины неполноты. Счётчики хранятся отдельно от коэффициентов чувствительности. Полнота не подменяет итог выполнения требования: доказанное нарушение сохраняет FAIL, одновременно может быть показана неполнота. Если известного нарушения нет, неполный расчёт не получает OK.

Проверена сеть с успешным радиальным режимом и параллельными идеальными аппаратами, где ток одного аппарата однозначно не определяется: основная зона проверена в 1 из 2 случаев, итог UNRESOLVED. Проверены отсутствующий решатель, ошибка резервной точки, ошибочный рабочий ток, NaN/Inf/отрицательный ток и сочетание FAIL с неполнотой. Пустая неприменимая зона резервирования сопровождается объяснением.

Тот же учёт ошибок выполнен в ТО. Общая сводка и код завершения командной строки учитывают неполноту. Отчёт селективности не заявляет успешную проверку всех режимов, если режим или пара не рассчитаны.

## 1В. ТО во всех применимых режимах

Внешний ток для отстройки выбирается по всем применимым состояниям. Метка `max` больше не ограничивает набор. Расчётная точка за трансформатором определяется для каждого режима с учётом направления питания; совпадающие электрические точки не дублируются.

Причины исключения отключённых и обесточенных режимов сохраняются. Обязательный режим с ошибкой решателя остаётся непроверенным. Равные определяющие режимы перечисляются; существующее правило выбора первого представителя по порядку объявления сохраняется. Численные допуски не изменены.

Независимый пример: режим с названием `min` имеет более сильную топологию. Расчётная граница ТО выросла с 2642,6061 до 4210,0988 А, принятая уставка — с 3000 до 5000 А. Ожидание получено из комплексных сопротивлений внешним проверяющим, без использования функции выбора уставки.

Дополнительная оценка зоны ТО по длине линии не выдаётся по частичному набору режимов. Если хотя бы один обязательный режим не допускает прежнюю одномерную оценку, выводится причина недоступности; новая методика зоны действия не вводилась.

## 1Г. Собственный бросок трансформатора

Условие броска проверяется и для самого защищаемого трансформатора. Кратность относится к номинальному току включаемой обмотки. Учитываются физическая сторона ТТ, обратное питание и идеальные включённые аппараты между элементами; один физический трансформатор не дублируется при обходе.

Для собственного трансформатора при радиальном включении со стороны ТТ используется заданная кратность и номинальный ток этой стороны. При ТТ на другой обмотке объясняется неприменимость собственного броска к этой точке измерения. Для нижестоящего трансформатора требуется единственный путь питания через защиту.

Отсутствующая кратность не заменяется единицей. Неопределённое направление включения и распределение броска при питании с двух сторон явно оставляют проверку неполной. Временная модель намагничивания и распределение переходного тока в многопитаемой сети не реализовывались.

Независимый пример: 6300 кВА, 35/6 кВ, Kбр=14, kотс.бр=1,3 и ТТ на 35 кВ. Граница броска `1,3·14·6300/(√3·35) = 1891,3995 А` определяет уставку; принятое значение меняется с 1200 до 2400 А. Другой пример без кратности меняет прежний OK на UNRESOLVED, сохраняя только предварительно рассчитанное число.
