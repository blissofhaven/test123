## Изменения

- Светлый выбор проекта, 12 недавних путей, пустой проект и создание своей копии
  учебного шаблона. Автооткрытие последнего выключено по умолчанию.
- Открытие через обычный запуск, явный путь, smoke и меню передаёт `calculate=False`.
  Старый программный API сохраняет значение по умолчанию `calculate=True`.
- Точечный запрос содержит неизменяемый вход, один режим, физический узел/порт
  и выбранные `FaultSpec`. Полный `ProjectResult` им не подменяется.
- Подготовка топологии выбранного режима повторно используется; каждый новый
  узел создаёт свой решатель. Совпадающий запрос использует кэш результата.
- Отдельные строки ошибок для недоступных видов КЗ. BCG показывает максимум
  модулей токов повреждённых фаз и сохраняет оба комплексных фазных тока.
- Запрос выполняется в фоне. Отмена, другой режим или изменённые электрические
  данные не позволяют опубликовать устаревшие числа. Геометрия не входит в
  электрический отпечаток, привязка блока следует за рисунком.
