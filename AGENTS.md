## Формат запуска при передаче архива

`ЗАПУСК.bat` сохранять как UTF-8 без BOM, с окончаниями строк Windows CRLF.
31.08.2026 ошибка повторилась после следующей распаковки: архив снова содержал
LF, Windows читала команды обрывками и возвращала код 0 без запуска окна.
Изменять код GUI для устранения этой ошибки не требуется.

До упаковки и после распаковки запускать
`python -m pytest -q tests/test_windows_launcher_format.py` — тест не требует Qt
и проверяет байты, а не текст с нормализованными переносами строк.
На Windows дополнительно проверять `ЗАПУСК.bat --smoke-test`: окно должно
открыться и закрыться, код возврата — 0, вывод — без ошибок командного файла.
Один только код 0 не является подтверждением успешного запуска.

В `.gitattributes` для BAT/CMD задано `-text`: рабочие CRLF сохраняются и в
Git-объектах, и в исходном ZIP. Одного `text eol=crlf` недостаточно для ZIP,
потому что внутри Git оно хранит LF. Не заменять это правило без проверки
байтов запуска из полученного архива.
