# Инструменты разработки

Для обычной работы с программой нужен `ЗАПУСК.bat` в корне, а не эти скрипты.
Инструменты перенесены из корня 01.09.2026; первый префикс `tools_` убран.

| Старое имя в отчётах и журналах | Текущий путь | Назначение |
|---|---|---|
| `tools_update_baseline.py` | `tools/update_baseline.py` | Сверка и только явно подтверждённое обновление эталона |
| `tools_autolayout.py` | `tools/autolayout.py` | Раскладка схемы с сохранением результата |
| `tools_build_demo_network.py` | `tools/build_demo_network.py` | Пересборка демо «Энергорайон» |
| `tools_build_substation_demo.py` | `tools/build_substation_demo.py` | Пересборка ПС «Промышленная» |
| `tools_rebuild_demo.py` | `tools/rebuild_demo.py` | Пересборка демо ГТЭС |

Новый отдельный учебный нефтепромысел строится инструментом
`tools/build_oilfield_demo.py`; его 34 листа оформляет `tools/oilfield_layout.py`.
Путь вывода обязателен, существующий файл защищён от случайной перезаписи:

```text
python tools/build_oilfield_demo.py --output ПУТЬ_К_НОВОЙ_СХЕМЕ.json
```

`--overwrite` явно разрешает заменить только указанный файл. Для обычного
открытия готовой `rza_calc/examples/oilfield_gtes.json` пересборка не нужна.
Импорт обоих новых модулей не пишет файлы. Все параметры нового проекта
учебные; методика и Z2/Z0 реального объекта не подтверждены.

## Безопасная сверка эталона

Из корня проекта, без разрешения записи:

```text
python tools/update_baseline.py --stage ПРОВЕРКА --reason "Проверка текущего состояния" --evidence "Без изменения эталона"
```

`--yes` разрешает запись и требует отдельного обоснованного задания.
Перенос скриптов не является таким заданием. Журнал
`docs/calculation-audit/baseline-log.md` и прежние отчёты сохранены: упоминание
старого имени в них читается по таблице выше, а не исправляется задним числом.

## Вызов и предостережения

`python tools/имя.py --help` показывает справку без пересборки и записи.
Можно передать Python абсолютный путь скрипта из другой рабочей папки:
он найдёт корень проекта относительно собственного файла.

**Генераторы и автораскладка при явном запуске меняют файлы демо/схем.**
Они не предназначены для открытия программы, проверки зависимостей или
автоматического «исправления» пользовательского проекта. Запускайте их только
для намеренной пересборки; тесты и эксперименты выполняйте в отдельной
временной копии, не перезаписывая рабочую схему.

У автораскладки явно заданный относительный путь проекта отсчитывается от
текущей рабочей папки; абсолютный путь не зависит от неё. Пути встроенных
демо, эталона и журнала вычисляются относительно корня этой копии проекта.

Регрессионные проверки переноса:

```text
python -m pytest -q tests/test_tool_entrypoints.py tests/test_repository_layout.py tests/test_calculation_baseline.py tests/test_roadmap_consistency.py tests/test_windows_launcher_format.py
```
